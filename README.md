# КУНАКИ — демонстрационный сайт

Сайт для показа визуальной концепции заказчику: https://anastasiaek.github.io/kunaki-site-demo/

Вариация с газетным коллажем России, чёрно-белыми руками и восходящим солнцем: https://anastasiaek.github.io/kunaki-site-demo/collage/ — подробности в `COLLAGE_VARIATION.md`.

Оригинальный логотип и фирменная палитра, девять смысловых разделов с полной навигацией: главная, о нас, направления, проекты, творчество и культура, команда, отчётность и документы, сотрудничество, контакты. Подробная сверка с авторской задумкой — в `AUTHOR_INTENT_REVIEW.md`.

Все изображения и шрифты загружаются локально. Сцены с людьми — созданные с помощью ИИ иллюстрации в российском контексте; это не фотографии команды или проектов АНО. Происхождение изображений указано в `dist/assets/photo-sources.json`, точные промпты — в `dist/assets/illustration-prompts.md`, лицензия Manrope — в `dist/assets/fonts/OFL.txt`.

Оригиналы устава и карточки организации в публичную демоверсию не включены. В разделе документов доступны запросы по электронной почте. Форма готовит письмо в почтовом приложении посетителя, сайт не хранит обращения. Платежи не подключены. Поисковая индексация отключена метатегом robots.

## Локальный просмотр

Открыть `dist/index.html` или запустить `python -m http.server 4173 --directory dist`.

## Docker

Запустить Docker Desktop и выполнить `docker compose up -d --build`. Адрес: http://localhost:8080. Остановка: `docker compose down`.

## GitHub Pages

Исходники — ветка `main`, опубликованные файлы — корень ветки `gh-pages`.

Обновление после редактирования:

```powershell
git add .
git commit -m "Update demo"
git push origin main
git subtree push --prefix dist origin gh-pages
```
