# КУНАКИ — демонстрационный сайт

Сайт для показа визуальной концепции заказчику: https://anastasiaek.github.io/kunaki-site-demo/

Вариация с газетным коллажем России, чёрно-белыми руками и восходящим солнцем: https://anastasiaek.github.io/kunaki-site-demo/collage/ — подробности в `COLLAGE_VARIATION.md`.

Мобильная адаптация версии с руками: горизонтальные ленты направлений и проектов, раскрывающиеся миссия, цель и принципы, руки над кнопками. Размеры экранов и проверки — в `MOBILE_LAYOUT.md`.

Оригинальный логотип и фирменная палитра, девять смысловых разделов с полной навигацией: главная, о нас, направления, проекты, творчество и культура, команда, отчётность и документы, сотрудничество, контакты. Подробная сверка с авторской задумкой — в `AUTHOR_INTENT_REVIEW.md`.

Все изображения и шрифты загружаются локально. Сцены с людьми — созданные с помощью ИИ иллюстрации в российском контексте; это не фотографии команды или проектов АНО. Происхождение изображений указано в `dist/assets/photo-sources.json`, точные промпты — в `dist/assets/illustration-prompts.md`, лицензия Manrope — в `dist/assets/fonts/OFL.txt`.

Оригиналы устава и карточки организации в публичную демоверсию не включены. В разделе документов доступны запросы по электронной почте. Формы отправляют обращения об идеях, волонтёрстве, партнёрстве и поддержке через FormSubmit на **kunaki-ano@mail.ru**. При ошибке отправки посетитель может скопировать текст или открыть письмо в своей почтовой программе. Платежи не подключены. Поисковая индексация отключена метатегом robots.

## Уведомления на почту

Получатель всех обращений: **kunaki-ano@mail.ru**. Для разных видов заявок используются отдельные темы писем; имя, контакты и сообщение передаются вместе. Если посетитель указал email, он добавляется в Reply-To.

Для включения доставки после публикации сайта:

1. Откройте опубликованный сайт и отправьте одну пробную заявку.
2. Откройте письмо FormSubmit в ящике **kunaki-ano@mail.ru** (проверьте также «Спам») и подтвердите адрес.
3. Отправьте ещё одну пробную заявку и проверьте получение письма. Если используете оба адреса сайта, проверьте каждую версию.

До подтверждения адреса доставка не включена. После принятия заявки сервисом сайт показывает «Заявка принята»; это подтверждает приём сервисом, а не доставку в почтовый ящик. FormSubmit хранит обращения до 30 дней. Подробности: https://formsubmit.co/documentation и https://formsubmit.co/help.

Проверки отправки в разработке выполняются с подменёнными ответами FormSubmit, без реальных писем. Для работы сервиса открывайте сайт по HTTP(S), а не как локальный HTML-файл.

## Локальный просмотр

Открыть `dist/index.html` или запустить `python -m http.server 4173 --directory dist`.

## Docker

Запустить Docker Desktop и выполнить `docker compose up -d --build`. Адрес: http://localhost:8080. Остановка: `docker compose down`.

## GitHub Pages

Исходники — ветка `main`, опубликованные файлы — корень ветки `gh-pages`.

Обновление после редактирования:

```powershell
git add .
git commit -m "Update demo"
git push origin main
git subtree push --prefix dist origin gh-pages
```
